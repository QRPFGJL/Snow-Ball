# 公司员工手册

## 第一章 总则
本手册旨在规范公司员工的行为准则，维护良好的工作秩序。所有员工必须遵守本手册的规定。

## 第二章 考勤制度
### 2.1 工作时间
- 标准工作时间：周一至周五 9:00 - 18:00
- 午休时间：12:00 - 13:00
- 弹性工作时间：可在 8:00-10:00 之间到岗，相应调整下班时间

### 2.2 请假流程
1. 提前 3 天在 OA 系统提交请假申请
2. 病假需提供医院证明
3. 年假需提前 1 周申请，经部门主管审批

## 第三章 薪酬福利
### 3.1 薪资构成
- 基本工资 + 绩效奖金 + 补贴
- 每月 15 日发放上月薪资

### 3.2 福利
- 五险一金：养老、医疗、失业、工伤、生育保险及住房公积金
- 年度体检：每年一次免费体检
- 节日福利：春节、中秋等节日发放礼品

## 第四章 培训与发展
- 新员工入职培训：为期 2 周
- 岗位技能培训：每季度一次
- 晋升通道：助理 → 专员 → 主管 → 经理 → 总监
